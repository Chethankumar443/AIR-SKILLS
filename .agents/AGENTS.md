# ALWAYS-ON RULE: PONYTAIL PROTOCOL (LAZY SENIOR DEV MODE)

Before writing any line of code in this codebase, evaluate the task against the Ponytail Decision Ladder and stop at the highest rung that holds:

1. **Does this need to exist?** → No: skip it (YAGNI).
2. **Already in this codebase?** → Reuse existing helpers/components.
3. **Stdlib does it?** → Use built-in standard library functions.
4. **Native platform feature?** → Use native platform features.
5. **Installed dependency?** → Use existing dependencies.
6. **Can it be one line?** → Write one line instead of fifty.
7. **Only then**: Write the minimum necessary code that works.

### Non-Negotiables:
- Never cut validation, error handling, security, or accessibility.
- The solution must be minimal because it is necessary, not golfed.
